Narakeet TTS Streaming Analysis

Empirical telemetry analysis on Narakeet HTTP streaming behavior:

API Protocol: Synchronous HTTP POST with Content-Length
Backend Synthesis Time: ~2.62s (TTFB before 1st byte)
Network Transfer Time: ~0.035s (21 chunks / 83 KB in 35ms)
Streaming Verification: Server Buffers Full Audio
Why speed feels unchanged: Narakeet generates the complete audio file on its backend before sending HTTP 200 headers with fixed Content-Length. Once generated, all 83 KB downloads across the network in just 35ms. Because Narakeet does not emit incomplete audio tokens as they are generated, client-side HTTP streaming (stream=True) cannot bypass the 2.6s server-side synthesis delay.
